# AURA — סוכנת שיווק AI אישית בווטסאפ

מערכת תגובתית: לכל לקוח סוכן שיווק פרטי בווטסאפ, שמנהל איתו שיחה ומייצר עבורו תוכן
שיווקי ממותג (קופי, הוקים, תמונות, סרטונים) **מתי שהלקוח פונה** — לא בשליחה מתוזמנת.
סוכן אחד משותף לכל הלקוחות; הזיהוי לפי מספר הטלפון, והתוכן נוצר לפי פרופיל המותג של אותו לקוח ב-DB.

## רכיבים

| רכיב | תפקיד |
|---|---|
| `src/index.js` | תהליך ראשי: מאזין להודעות ווטסאפ (polling) + מרים את פאנל הניהול. **אין מתזמן — המערכת תגובתית.** |
| `src/admin.js` + `public/` | פאנל ניהול לקוחות (UI) — הזנת פרופיל מותג, שמירה ל-DB, "צור תוכן עכשיו" |
| `src/agent.js` | הסוכן: Claude לטקסט + כלים `generate_image` (create/edit) / `generate_video` |
| `src/openai_images.js` | תמונות בצ'אט — OpenAI Responses API (יצירה + עריכה המשכית) |
| `src/visual.js` | Seedream (תמונות) + Seedance (וידאו), OpenAI כגיבוי |
| `src/daily.js` | בונה חבילת תוכן ידנית לכפתור "צור תוכן עכשיו" (הפעלה יזומה, לא מתוזמנת) |
| `src/greenapi.js` | שכבת ווטסאפ (שליחה, קבלה ב-polling) |
| `src/auth.js` | אבטחת פאנל הניהול (hash סיסמה, סשן חתום, rate-limit) |
| `src/db.js` | SQLite — לקוחות, היסטוריה, מצב תמונות, שימוש חודשי |

## איך זה עובד

הלקוח כותב בווטסאפ, ו-Claude (המוח) מזהה את הכוונה ומגיב לפי פרופיל המותג:

- **קופי/הוקים/קרוסלות** — נוצרים בעברית לפי הטון, הקהל והמסרים שבפרופיל.
- **תמונה חדשה** ("תכין תמונה של תרנגול") — `mode=create`, פרומפט אנגלי עם צבעי המותג והסגנון.
- **עריכת התמונה האחרונה** ("תגדיל", "רקע כחול", "יותר שמח") — `mode=edit` דרך OpenAI Responses API
  עם `previous_response_id`, ששומר על אותו נושא, סגנון וצבעים. **עד 3 עריכות לתמונה**, ואז המערכת
  אומרת ללקוח לבקש תמונה חדשה.
- **וידאו** — סרטון מוצר קצר (Seedance). ניתן לעריכה אחת.
- אם לא ברור אם רוצים תמונה חדשה או עריכה — Claude שואל את הלקוח קודם.

לכל לקוח נשמר `last_response_id` + snapshot של פרופיל המותג מזמן היצירה (טבלת `image_state`),
כדי שעריכות יישארו עקביות גם אם הפרופיל השתנה. היצירה נספרת מול המכסה החודשית של החבילה.

## התקנה והרצה

```bash
cd aura
npm install
cp .env.example .env    # ולמלא מפתחות
npm start               # מאזין לווטסאפ + פאנל ניהול (localhost:3000)
```

פאנל הניהול: http://localhost:3000 — מזינים סיסמה, מוסיפים לקוח, ממלאים פרופיל מותג, שומרים.
כפתור "צור תוכן עכשיו" מייצר ושולח תוכן ללקוח באופן יזום.

בדיקות ותחזוקה:

```bash
npm run smoke                       # בדיקת עשן בלי קריאות API
npm run check-wa                    # מוודא שהחיבור לווטסאפ (Green API) authorized
npm run check-wa -- 972501234567    # גם שולח הודעת בדיקה למספר
npm run admin                       # פאנל הניהול בלבד
npm run hash-password -- "סיסמה"    # יוצר ADMIN_PASSWORD_HASH לפרודקשן
```

## מפתחות (`.env`)

| משתנה | מאיפה |
|---|---|
| `GREEN_API_ID_INSTANCE` + `GREEN_API_TOKEN` | Green API — Instance מחובר למספר ווטסאפ |
| `ANTHROPIC_API_KEY` | מנוע הטקסט (Claude) |
| `OPENAI_API_KEY` + `OPENAI_RESPONSES_MODEL` | תמונות בצ'אט (Responses API) |
| `BYTEPLUS_API_KEY` + `SEEDREAM_MODEL` + `SEEDANCE_MODEL` | תמונות ווידאו (Seedream/Seedance) |
| `ADMIN_PASSWORD_HASH` + `SESSION_SECRET` | אבטחת פאנל הניהול |

## אבטחת פאנל הניהול

מנהל יחיד, סיסמה אחת, מוקשח לרשת: סיסמה כ-scrypt hash, סשן בטוקן חתום ב-cookie
(`HttpOnly` + `SameSite=Strict` + `Secure`), והגבלת קצב על ניסיונות כניסה.

לפרודקשן:

```bash
npm run hash-password -- "סיסמה-חזקה-שלך"
# מעתיקים את הפלט ל-ADMIN_PASSWORD_HASH ב-.env, מוחקים את ADMIN_PASSWORD.
```

וגם מגדירים `SESSION_SECRET` למחרוזת אקראית ארוכה.

## הערות

- **Polling ולא webhook** — המערכת מושכת הודעות מ-Green API, אז רצה גם ממחשב מקומי בלי כתובת ציבורית.
- **חשבון ווטסאפ נפרד** — מספר AURA (למשל 019) הוא חשבון ווטסאפ נפרד מהאישי שלך; הלקוחות שולחים אליו,
  ו-AURA עונה אוטומטית מהשרת. את לא צריכה לראות את ההודעות.
- מספרים שאינם ב-DB — המערכת מתעלמת מהם.
